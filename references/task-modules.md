# 按任务补充的模块

只启用影响当前决定的模块，不是通用测试清单。

## 分类、决策与概率

- 报类别支持数、混淆矩阵、逐类 precision/recall/F1；区分 micro/macro/业务权重。稀有高风险类不能被总体 accuracy 淹没；0 分母指标标未定义并披露规则。
- 固定标签映射、无效输出、拒判和多标签解析。多标签区分逐标签质量、样本整组正确率和业务关键标签。
- 阈值在开发集选择并冻结。给高风险错误代价、阈值—召回/误报、人工覆盖率—剩余风险关系；不在最终测试上选阈值再报无偏收益。
- 有可比较概率时评估 Brier/log loss、校准图/分箱，注明分箱与样本支持。模型自述“90% 自信”不是经校准的概率。
- 因果干预、策略收益或排序/推荐任务先确认离线标签能否识别政策收益；历史动作影响观测时不能用 accuracy 宣称线上收益，需要相应反事实/在线实验设计；证据不足则限制结论。

## 语义等价扰动

分开**正确性、同输入重复稳定性、语义等价输入稳定性**。

原始任务为 group_id，变体有独立 case_id；包括选项顺序、标签同义词、格式、非关键信息和等价改写。先确认语义保持，尤其否定、时间、量词与选项映射。输出映射回语义标签再比较，不直接比 A/B 字母。

- 变体翻转率 = 语义决策相对原题改变的有效配对数 / 有效配对数，同时报解析失败与无效配对。
- 组内完全一致率 = 所有预定变体语义决策一致的组数 / 覆盖完整组数，披露不完整组数。
- 同时报最差变体质量、原题质量与重复调用基线波动。

一致地答错仍是错误。多变体不是独立样本，对组重采样。无翻转不证明正确或对所有扰动鲁棒。

## 开放生成与 RAG

- 分开正确性、完整性、遵循指令和表达；关键事实错误不能被可读性抵消。允许多种有效表达。
- RAG 分开检索覆盖（需要何种证据、是否找回）和生成质量（忠于可见证据、引用支持具体主张）。来源可访问不等于主张获支持。
- 覆盖可回答与不可回答任务；信息不足时恰当澄清/拒答是成功条件之一。
- 记录语料/索引时间、分块、召回/rerank、上下文预算。固定上下文比较生成环节；端到端含检索系统，不混淆归因。
- 长上下文/多模态按证据位置、长度、图像分辨率或音频质量等相关因素切片；不外推至未测模态/长度。

## Agent、工具与长任务

以**任务终态**判定成功：文件内容、数据库状态、测试结果、操作结果等产物。仅有“已完成”回复或工具成功码不证明业务目标完成。

分开任务成功、步骤/工具选择、参数与权限、恢复和重复执行副作用。轨迹用于解释失败；最终成功也可能含不可接受的越权步骤，风险门槛独立检查。

每次 trial 固定初始快照、工具版本/权限、网络、预算与停止条件。隔离状态并记录调用、重试、超时和环境异常；对外副作用用授权隔离环境，不能为评测擅自发消息或改生产数据。

按使用目标选择随机性指标：

- 单次成功率：从初始状态运行的部署体验，写清内部重试预算。
- 经验 any-of-k：固定 k 次 trial 至少一次成功的任务比例。
- 经验 all-of-k：固定 k 次 trial 全部成功的任务比例。

同样 k、覆盖完整、取样明确的组才能直接比较经验指标。若用标准 pass@k 估计器，n 个可交换候选中 c 个成功且 n >= k，每题估计为 `1 - C(n-c,k)/C(n,k)`；说明估计器、生成方式、k 与额外开销。不把多次挑最优冒充部署单次成功率。`p**k` 仅在适当独立同分布假设下是全部成功概率，不能用总体均值的幂代替异质任务的实测可靠性。

恢复测试按风险选择中断、限流、工具故障、重复请求、过期状态；检查恢复、重复扣费/写入及权限。能重试不证明幂等。
